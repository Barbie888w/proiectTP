#TIK-TAK-TOE

1. Arhitectura de Date

    Structura: Folosirea unei matrice 3x3 de tip char pentru a stoca starea tablei de joc.

    Logica de calcul: Cum transformi cifra introdusă de utilizator (1-9) în coordonate de matrice (i, j) folosind operatorii / (div) și % (mod).

    Validarea: Mecanismul prin care programul refuză mutările pe căsuțe ocupate sau caracterele invalide.

    Sistemul de culori: Utilizarea codurilor ANSI pentru a schimba aspectul consolei.


2. Mecanica Jocului

    Verificarea celor 8 linii posibile de câștig (orizontal, vertical, diagonal).

    Condiția de remiză când matricea este plină și nu există câștigător.

3. Atribuții noi (posibil)

    Putere 1: abilitatea de a sterge caracterul celuilalt jucator si de a pune caracterul personal peste.
